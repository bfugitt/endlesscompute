⚡ HOW TO PLAY COMPUTE-IT

In typical programming, you write the code. In ComputeIt, YOU are the computer! Your job is to read the code instructions and translate them into keyboard movements.

The Mission

Drive your glowing cursor from the Start Circle to the green glowing Finish Goal by pressing Arrow keys perfectly matched to the program instructions.

Instruction Types:

➡️
Sequential Commands MOVE RIGHT means press your Right Arrow key.
🔄
Loops (Repeat Block) REPEAT 3 TIMES: MOVE UP means press Up Arrow 3 times in a row!
❓
Conditionals (If / Else)

Check the glowing color under your player cursor tile:

IF tile is RED: MOVE UP ELSE: MOVE LEFT
